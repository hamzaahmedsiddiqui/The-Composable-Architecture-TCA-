# The Composable Architecture (TCA) — Complete Textbook

A full, university-style textbook that teaches TCA from zero to advanced,
for iOS engineers using Swift 6 and modern SwiftUI.

## How to use this book

Each chapter is its own file in this folder. Read them in order — later
chapters assume you understood the ones before. Every chapter follows the
same teaching pattern: plain-English explanation → why it exists → problem
it solves → how it works internally → diagrams → examples → line-by-line
code walkthrough → common mistakes → best practices.
